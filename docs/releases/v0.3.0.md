# Coopanion v0.3.0

**她可以自己上网逛逛；大肥鱼多了工装、睡裙和十四个动作；电脑操作可以在后台只动一个窗口，不碰你的鼠标**

## 新功能

- **自己的浏览器和闲时上网**:在「习惯」页打开「自己的时间」后,一段时间没聊天(默认 20 分钟)她会得到一段自己的时间,打开独立的浏览器窗口去 B站、抖音或别处看看、播放视频、滚动和看评论;打开互动开关后,也可以点赞、收藏、关注、发弹幕和评论。登录、验证码和支付由你自己完成,窗口默认静音,可在同一节打开浏览器声音。这个窗口的登录状态和你的浏览器分开。
- **自己的时间不设上限**:「每次最多」旁边多了「不限」,打开后不按时长自动关闭,她关上浏览器才结束;最短安静时间改为 1 分钟。
- **按文字点击和悬停**:没有编号的按钮(例如发布页的「添加音乐」)可以按可见文字点击;只在悬停后出现的按钮(例如选音乐的「使用」)可以先移到上面,再读一次页面,然后点击。输入改用 Chromium 的真实文本输入,页面编辑器能收到文字。
- **后台操作一个窗口**:装了 [Cua Driver](https://github.com/trycua/cua) 并授权辅助功能和屏幕录制后,她可以选中一个窗口做后台操作:截图、点击、拖动、滚动、打字和按键都只作用于这个窗口,不移动你的鼠标,也不抢焦点。整屏操作仍然会在你动鼠标或键盘时让位。
- **大肥鱼的工装和睡裙**:工装是无袖深蓝背心配浅灰蓝工装裙、鲸鳍形袖口翻边、腰侧小鲸鱼挂件和高马尾;睡裙是淡蓝水手领睡裙、双麻花辫,穿它睡觉时身下出现贝壳床、月亮抱枕、被子和床头灯。装扮页现在有五套服装。
- **大肥鱼的十四个动作**:捂脸偷看、喷水、抱尾巴、游泳、抖水、吹泡泡、飘浮、蹲着画圈、敲屏幕、探头、伸懒腰、装死、拍尾鼓掌和打喷嚏;甩尾巴落地时带上水花和新的落地声。

## 修复

- **自己的时间的设置范围**:安静时间现在可以从 1 分钟起设;手改超出范围的值按边界读入,不再退回默认值。
- **互动开关的说明**:设置里的文字现在写明也可以发评论。
- **本地语音**:GPT-SoVITS 适配器会读取配置里的 `temperature` 并传给服务。

## 改动

- 这个版本基于 Coopanion v0.2.8,下载和自动更新都在本仓库进行。
- 大肥鱼的形象包新增 `night` 和 `work` 服装。没有安装 Cua Driver 的机器上 `pet_cua_window` 不可用,其余电脑操作照旧。
