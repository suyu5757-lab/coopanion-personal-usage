# Coopanion v0.4.0

Released 2026-10-27. Feature update from this repository's v0.3.0.

## New features

- **OpenCode and terminal guest**: delegate coding through the local ACP bridge, answer permission requests and review changes. A terminal guest shows working, waiting, done and error states.
- **Codex assistant**: `codex_task`, `codex_status`, `codex_review` and `codex_stop` delegate authorized analysis, coding and review to a local Codex CLI. Coo receives and reviews the background result. Includes read-only tasks, allowed directories, timeout, cancellation and continuation of the same task. OpenCode remains available independently.
- **Self-review**: every 7 days by default, Coo reviews recent experiences and her Hindsight self-portrait after at least 15 quiet minutes while unpaused. Disable it or choose 1–60 days in Habits. Workspace changes retain Git history; constitution changes apply to subsequent sessions. Failures retry after one hour.
- **Video observation**: `browser_watch` returns multiple frames and can transcribe the page audio using local speech recognition. Unavailable audio is reported alongside the available frames.
- **Browser sharing**: `browser_share` opens a video's share panel when interactions are allowed. Coo can then share the retrieved link in conversation.
- **Emotion references for local speech**: the GPT-SoVITS adapter selects references, auxiliary audio and sampling parameters from explicit emotion markers. Unspecified emotions use the default reference; keyword guessing is off by default.

## Fixes and changes

- Start or reuse a valid Cua Driver session before each operation; never automatically repeat a failed input action.
- Add `worlds.desktop-pet.cua.backgroundOnly`: when enabled, input requires a selected background window, foreground focus is refused, and a missing target never falls back to whole-screen input.
- Report useful driver errors when the primary error field is empty.
- Update the whale persona, add usage contexts for expressions and motions and refine action combinations.
- Enable time of her own for configurations adopting the new defaults; preserve explicitly saved switches. Sound and interactions retain their separate controls.
- Support emotion-specific auxiliary references, sampling settings and isolated adapter configuration. Adjust speech chunks and gaps. Installing the example voice requires explicit opt-in.
- Include the missing Hindsight client runtime dependency in installers. Bundle Codex as an optional World, disabled by default.

## Upgrading and configuration

Existing application data is reused. The previously removed affinity extension stays uninstalled on this Mac; its preserved relationship data is not deleted or migrated by the installer. Packages contain no personal credentials, sign-in state, conversations, relationship records, voice references or model weights.

Install and sign in to Codex CLI separately, enable its World in advanced settings, and configure its executable and allowed directories. Existing same-name extension configuration remains applicable; the bundled World takes precedence. See `packages/cortico-world-codex/README.md`.

Background-only input is optional, off by default and requires macOS Cua Driver. Existing explicit configuration is preserved.

Local voice tools in `personal-voice/` require separate setup. Updating the app does not reinstall a local voice environment or distribute third-party extensions, weights or reference recordings. Emotion markers require the corresponding streamvoice patch. Self-review can increase model and Hindsight usage and can be disabled in Habits.

## Known limitations

- Cua Driver 0.37.0 has a recorded native crash on the background keyboard path on macOS 14.8.7. Background typing and keys remain unverified; stop and report failures while keeping an enabled background-only restriction.
- Auxiliary speech references and sampling changes do not guarantee elimination of distorted syllables or timbre changes; audition your configuration.
- Codex requires a separately installed and configured CLI. This release is built and validated for the owner's Apple silicon Mac.
- macOS builds are ad hoc signed and not notarized. Follow the README to open them and re-add system permissions if needed after updating.
