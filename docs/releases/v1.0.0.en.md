# Coopanion v1.0.0

Released 2026-11-16. The first formal 1.0 release, built on v0.4.0.

## Highlights

- **One long-term memory across five domains.** Persona, relationship and preferences, project history, skills and methods, and social context are carried by Hindsight long-term memory and the SourceDomainIndex. Historical claims in a reply come from verified sources with SourceProof; workspace files no longer stand in for remembered history.
- **The old notes feature is gone.** The dual-track note read mode, automatic full file listing injection, the old memory-page note entries and their copy have been removed from the source. The workspace is still read and written on demand, but a file is task material marked as unverified history.
- **Production SQLite v5.** The memory state database is v5, with source domains, generation evidence and derived artifacts. Existing events, receipts, Forget state and fences are preserved; the Bank is not rebuilt.
- **Source safety.** Forget/fence/epoch, ActionGate, ActionReceipt and the complete-evidence requirement remain in force; a forgotten source cannot return through an old file, a cache or an artifact.
- **Companionship and existing abilities.** The tsundere-but-natural Persona, proactive conversation, growth candidates, OpenCode/Codex helpers, browser, computer use and the GPT-SoVITS voice chain keep their existing behaviour.

## Upgrading

- An over-install keeps the existing data directory, Persona, sessions and long-term memory. The Bank is not rebuilt and historical records are not redelivered.
- The macOS build is still ad-hoc signed and not notarized; after an update, Accessibility, Screen Recording and similar permissions may need to be granted again in System Settings.
- This release does not mean N4–N6, all voice work or the full N7 acceptance is complete; unfinished modules continue on their own plans.
