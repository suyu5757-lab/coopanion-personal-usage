# Coopanion v1.0.0

Released 2026-11-23. The first formal 1.0 release built on v0.4.0, with all 14/14 live verification gates passed.

## Highlights

- **Five-domain unified long-term memory & cross-epoch evidence recovery.** Hindsight + SQLite v5 + SourceDomainIndex unify Persona, preferences, project history, skills, and social context, with verified `memory_remember`, local-outbox `memory_correct`, and non-blocking `memory_forget` cross-epoch proof recovery.
- **Unified experience & growth engine.** Five-domain soft indexing, `supersedesId` supersession, feedback retirement (`recordFeedback`), and strict provider isolation between web-image and Douyin lessons.
- **Native local ComfyUI integration (Anime Studio v5.1 MCP + Skill).** Bundled `anime-studio` World bridging to local `mcp_server.py` over stdio JSON-RPC with 4 async-safe tools (`anime_studio_assets`, `anime_studio_submit`, `anime_studio_job`, `anime_studio_jobs`) and full Core schema/prompt/outcome trust roots.
- **Desktop companionship, E12 voice sync & macOS CUA.** Playback-clock-synced speech bubbles and guarded macOS desktop CUA.
- **Built-in browser dual-site image workspace & Douyin creator pipeline.** ChatGPT/Gemini image workspace management, Douyin publish pipeline with in-place BGM verification, and fast same-origin `work_list` metrics snapshot readback.

## Upgrading

- Over-installing preserves existing data directories, Persona, sessions, and Hindsight memory without rebuilding the Bank.
- macOS installers are ad-hoc signed and not Apple-notarized; re-grant Accessibility / Screen Recording permissions in System Settings if prompted after updating.
