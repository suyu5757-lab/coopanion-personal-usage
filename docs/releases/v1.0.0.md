# Coopanion v1.0.0

发布日期：2026-11-16。基于 v0.4.0 的第一个正式 1.0 版本。

## 主要变化

- **五领域统一长期记忆**：Persona、关系与偏好、项目历史、技能方法、社会语境由 Hindsight 长期记忆与 SourceDomainIndex 统一承接；回复中的历史内容走真实来源与 SourceProof，不再由工作区文件冒充。
- **旧笔记功能正式退场**：旧笔记双轨读取模式、全量文件列表自动注入、旧记忆页的笔记入口和旧文案已从源码移除。工作区仍可按需读写，但文件只作为任务材料，标记为未核实的历史来源。
- **生产 SQLite v5**：长期记忆状态库升级到 v5，包含来源域、生成证据与派生工件；升级保留既有事件、回执、Forget 与 fence，不重建 Bank。
- **来源安全**：Forget/fence/epoch、ActionGate、ActionReceipt 与完整证据要求继续生效；被遗忘的来源不会因为旧文件、缓存或工件而复活。
- **桌面陪伴与既有能力**：傲娇而自然的 Persona、主动交流、自我成长候选、OpenCode/Codex 助手、浏览器、电脑操作、GPT-SoVITS 语音链保持既有行为。

## 升级说明

- 覆盖安装后继续使用原有数据目录、Persona、Session 与长期记忆；不会重建 Bank，也不会重新投递历史记录。
- macOS 安装包仍为临时签名、未经 Apple 公证；更新后可能需要在系统设置中重新授予辅助功能、屏幕录制等权限。
- 本版本不代表 N4–N6、全部语音与完整 N7 总验已经完成；未完成模块仍按各自计划推进。
