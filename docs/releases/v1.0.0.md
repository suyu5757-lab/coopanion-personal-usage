# Coopanion v1.0.0

发布日期：2026-11-23。基于 v0.4.0 的第一个正式 1.0 完整封口版本（全量 14/14 实机验收通过）。

## 主要变化

- **五领域统一长期记忆与来源证据闭环**：Persona、关系偏好、项目历史、技能方法与社会语境统一由 Hindsight + SQLite v5 + SourceDomainIndex 承接；完整打通 `memory_remember`、`memory_correct`（含本地 outbox 来源解析）与 `memory_forget` 跨 epoch 证据恢复链路（同步清心理模型防复活、异步重建防卡死、零证据闸门误阻断）。
- **统一成长与经验引擎（OperationExperienceLog）**：支持五领域软索引、时序取代（`supersedesId`）、效果反馈淘汰（`recordFeedback`）与严格 Provider 分区隔离（生图与抖音经验互不串台）。
- **原生本地 ComfyUI 生图集成（Anime Studio v5.1 MCP + Skill）**：新增内置 `anime-studio` World（零依赖 stdio JSON-RPC MCP 客户端直连本地 `mcp_server.py`），暴露防超时的 4 个异步任务队列工具（`anime_studio_assets` / `anime_studio_submit` / `anime_studio_job` / `anime_studio_jobs`），完整接入 Core Tool Schema Digest、Prompt 信任根与 `worldToolOutcomeTrust`。
- **桌面陪伴、E12 语音同步与 macOS 桌面 CUA**：语音气泡与 E12 播放时钟对齐、防空泡/乱序；macOS 桌面 CUA 支持窗口感知与安全护栏（严禁触碰个人微信）。
- **内置浏览器双站生图与抖音创作者全链路**：支持 ChatGPT / Gemini 网页生图工作区管理；抖音创作者中心支持一步准备草稿、编辑页配乐真导入校验与防跳页自毁、以及同源 `work_list` 高速 API 数据快照回读（2–3 秒完成落盘）。
- **旧笔记功能正式退场**：工作区文件仅作为任务材料与标准 Skill SOP（`douyin-publish-sop.md`、`web-image-sop.md`、`desktop-cua-sop.md`、`wechat-xi-sop.md`、`anime-studio-sop.md`），不冒充历史事实来源。

## 升级说明

- 覆盖安装后继续使用原有数据目录、Persona、Session 与长期记忆；不会重建 Hindsight Bank，也不会重新投递历史记录。
- macOS 安装包为本地自签名/临时签名（未经 Apple 公证）；覆盖更新后如系统提示权限失效，请在「系统设置 → 隐私与安全性」中重新勾选辅助功能与屏幕录制权限。
- 抖音创作者中心（`creator.douyin.com`）线上数据回读需保持 VPN 关闭；本地 ComfyUI 生图需先运行本机 ComfyUI 服务（`http://127.0.0.1:8188`）。
