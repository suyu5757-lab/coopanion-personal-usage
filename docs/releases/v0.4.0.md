# Coopanion v0.4.0

发布日期：2026-10-27。基于本仓库 v0.3.0 的功能更新。

## 新功能

- **OpenCode 与终端客人**：通过本机 ACP 桥接委派编码任务，支持权限答复、状态、停止和结果复核；桌面终端客人显示工作、等待、完成和出错状态。
- **Codex 执行助手**：新增 `codex_task`、`codex_status`、`codex_review`、`codex_stop`。Coo 可以把授权范围内的分析、编码和复核任务交给本机 Codex，后台执行后接收结果并验收。支持只读任务、允许目录、超时、取消和同一任务续接。OpenCode 保留为独立执行器。
- **自我成长**：默认每 7 天，在安静至少 15 分钟且未暂停时回顾近期经历和 Hindsight 自我画像。可在「习惯」页关闭或将间隔设为 1–60 天；记录写入工作区，修改保留 Git 历史，人设变化从后续 session 生效。失败后 1 小时重试。
- **视频多帧观察与语音转写**：`browser_watch` 可在观察期间返回多张画面，并通过本机语音识别提供页面音轨的转写。音轨不可用时保留画面并报告原因。
- **浏览器分享**：新增 `browser_share`，打开当前视频的分享面板；互动关闭时拒绝执行。可将获得的视频链接通过对话分享给使用者。
- **表情驱动的语音参考**：本地 GPT-SoVITS 适配器接收显式情绪标记，并按配置选择参考音、辅助参考和采样设置。未指定情绪时使用默认参考；正文关键词猜测默认关闭。

## 修复与调整

- Cua Driver 操作前幂等启动命名会话，避免持续复用已过期会话；失败的输入动作不会自动重发。
- 新增 `worlds.desktop-pet.cua.backgroundOnly` 保护：启用后，必须先选中后台窗口才能点击、拖动、滚动、输入或按键，并拒绝前台聚焦；目标窗口消失时不回退整屏输入。
- 修复驱动空错误文本的回报，保留可用错误原因。
- 大肥鱼人设、表情和动作词表补充使用情境，调整单次动作的组合方式。
- 「自己的时间」对采用新默认值的配置开启；已经显式保存的开关保持原值。互动和声音仍由各自设置控制。
- 本地语音支持情绪级辅助参考、采样参数和独立测试配置；调整分块与句间间隔。示例音色安装要求显式选择，避免无意覆盖现有配置。
- 修复安装包缺少 Hindsight 客户端运行依赖的问题；Codex 模块随安装包提供，默认关闭。

## 升级与配置

- 本机此前已卸载阻塞启动的好感度扩展，本次不重新启用；保留的关系数据不删除、不迁移。
- 更新应用后继续使用原有数据目录。安装包不携带个人 API Key、登录状态、聊天、关系记录、语音参考或模型权重。
- Codex：先自行安装并登录 Codex CLI，在高级模式 World 页启用 Codex，填写可执行文件路径和允许的工作目录。已安装同名 Codex 扩展的配置继续使用；内置实现优先，同名扩展无需重复加载。详情见 `packages/cortico-world-codex/README.md`。
- 后台输入保护可在电脑操作设置中开启。默认关闭，已有显式配置保持原值；启用后依赖 macOS Cua Driver。
- 语音适配器、安装脚本与补丁在 `personal-voice/`，属于需要单独配置的可选功能。已有本地语音安装不会随应用更新被重装；音色权重、参考音和第三方扩展不随安装包分发。情绪标记需要 streamvoice 对应补丁，参见该目录说明。
- 自我成长可能增加模型与 Hindsight 调用，可在「习惯」页关闭。

## 已知限制

- Cua Driver 0.37.0 的后台键盘路径在 macOS 14.8.7 仍有原生崩溃记录。后台打字与按键尚不能认定可用；遇到故障应停止并报告，保持已启用的后台输入保护。
- 语音参数调整与辅助参考不保证消除所有破音或音色变化，仍需使用者试听选择。
- Codex 复用本机 CLI 登录与配置；未安装 CLI 或未配置允许目录时不能执行任务。本次按使用者的 Apple 芯片 Mac 构建和验证。
- macOS 安装包采用临时签名，未经 Apple 公证，需按 README 的系统设置步骤打开。应用更新后可能需要重新添加录屏、辅助功能等授权。
