## Tool result behavior

`growthMemorySearchTool()` now captures the Memory evidence epoch before recall, asks Hindsight for exact read-back attachments, and returns `ToolOutcome.evidence` only for the spans returned by the formatter. Each attachment must match a source tuple, span, digest, current epoch, current revision and validated read-back. The code adds observed Growth source IDs only for spans that pass those checks.

The complete result gate requires all formatted source segments to have matching attachments and the attachments to cover the entire displayed text. When the formatter adds explanatory labels or boilerplate beyond the verified source excerpts, the tool returns those validated excerpt attachments with the incomplete-evidence notice. It does not expand the source spans to include formatter text or treat the whole block as complete.

Growth proposal handlers now query `CoreApi.generationEvidence(ctx.sessionId ?? ctx.role)`. Cortico runs Growth in a fork with a distinct session ID, so using the role name did not locate that fork’s envelope.

## Real Core/FakeLLM result

The surrounding formatted text remains explicitly incomplete. Formatter `source_id` strings alone do not establish source evidence.

This is the remaining C2-11 blocker: Growth’s end-to-end model generation cannot reach a valid proposal until the complete request is mapped. Existing approval, revision and lifecycle checks do not turn this incomplete generation into an accepted proposal.

## Forget approval/apply races

Two added end-to-end synthetic tests cover real Persona calls using real SQLite and a temporary workspace:

- `rejects Growth approval when Forget wins during source verification`: a candidate and provenance row are prepared with a synthetic current source; a source read pauses, Forget commits, and the approval route refuses the candidate. It stays `candidate`; its artifact becomes stale.
- `stops a controlled Growth apply when Forget changes the source epoch during read-back`: an approved synthetic candidate is checked in a temporary `WorkspaceGit`. Forget commits after source read-back but before the final epoch comparison. Apply refuses to write or commit; the workspace file and proposal remain unchanged, and provenance stays stale.

These are race tests over pre-existing candidates. They do not claim a successful model-generated approval or a public Growth apply; the public apply route remains disabled. The apply test’s Git workspace and all source values are test fixtures.
