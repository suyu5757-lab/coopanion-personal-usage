# C2-A system-prefix source map — owner: `Core.buildSystem` and the provider request evidence contract

## Result

`C2_A_FOCUSED_PASS_LOCAL`. A source-bearing Handoff now has a verifiable source span in the next Session's serialized provider request. The mapped Memory span is complete; dynamic Workspace text remains incomplete. `actualEvidenceUsed` remains `unknown`.

## Mapping path

1. `Cortico` assembles `PrefixSegment[]` for `buildSystem`. Each segment may declare digest-bound source spans. Core fills uncovered non-whitespace text as `unknown-derived`, stores the spans on the system `ContextRecord`, and keeps their offsets in the concatenated system text.
2. Cormini marks only the exact built-in orientation, seed Constitution and empty-workspace default as `core-generated`. World prompts and other dynamic prefix text have no trusted origin annotation.
3. Coo locates the exact `partnerDoc()` string once inside the rendered PARTNER segment. It maps the fixed PARTNER notice as generated text, reads each derived paragraph's source IDs back through `evidenceForSegments`, and marks the paragraph `hindsight-source` only when every ID has a valid current source tuple and the read-back covers the rendered paragraph. User-authored, withheld, stale or ambiguous paragraphs remain `unknown-derived`.
4. Before each provider dispatch, Core inspects the final serialized JSON body. It records the SHA-256 of the serialized body and exact string-leaf paths, UTF-16 offsets and span digests. The request-ready gate checks generation currency and Coo's current local bank, endpoint, Forget fence, evidence epoch and revision state. A rejected request is stored as `unobserved/stale` and is not dispatched or resubmitted.

## A2 trace

The synthetic integration fixture uses a source-backed PARTNER paragraph containing an astral Unicode character. After the source-bearing Handoff commits, Core resets and injects into the new Session, rebuilds the system prefix and serializes the next request.

- The PARTNER `hindsight-source` span has `mappingState: complete`, the same full source tuple as the request envelope, a span digest, and one serialized range in `$.instructions`.
- The test parses the serialized body and verifies that `field/start/end` slices the exact PARTNER paragraph. The range length is the JavaScript UTF-16 length, including the astral character, and its digest matches the text.
- The dynamic Workspace marker maps to `unknown-derived/missing`. The system item and full request stay incomplete, so the known Memory span does not upgrade unknown text to complete.
- The request keeps `actualEvidenceUsed: unknown`; mapping source availability does not claim the model used that source.

## Failure handling

- Missing source read-back leaves the source unexposed and the request incomplete.
- Duplicate serialized text is `ambiguous`; the source is not exposed.
- A Forget fence or locally verified revision inserted after serialization but before dispatch leaves the source span stale, records an unobserved request and leaves the provider dispatch count unchanged.
- A generation change during system rebuilding prevents stale Handoff publication. Main, fork and shutdown generation state remains isolated by the existing generation lease.
- A lost or evicted Core evidence entry stays incomplete. No unlabeled source path is treated as complete.
- IPC-derived evidence has no C2-A Memory mapping adapter: `IPC_EVIDENCE_UNSUPPORTED_FAIL_CLOSED`.

## Scope and evidence limits

The request boundary was exercised with a real Core/Persona integration, a synthetic local Hindsight HTTP server and a scripted LLM that serializes the production Responses-compatible body. The production HTTP transport was separately tested with a stubbed `fetch`; a rejected request made zero fetch calls and was not retried.

The send gate rechecks local visibility, Forget, epoch and revision state. The synthetic tests do not establish behavior against remote Hindsight mutations that have not entered local state. No formal App, real Hindsight Bank, private data, paid model request or external provider request was used. This pass is local C2-A evidence only.
